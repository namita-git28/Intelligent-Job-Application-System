📘 Intelligent Job Application Manager (Agentic AI)
An Agentic AI-powered full-stack web application designed to help users track, analyze, and optimize their job applications using data-driven insights and LLM-based reasoning.
This project demonstrates end-to-end product development, combining AI agents, analytics, and full-stack execution.

🚀 Features 🔐 Authentication
Secure user login & signup
User-specific data isolation

📊 Application Dashboard
Total applications overview
Application status breakdown (Applied, Interview, Rejected, Offer)
Weekly application trends

🗂️ Job Application Management
Add, edit, delete job applications

Track:
Company name
Role
Location
Job description
Application date
Status
Application link
Notes per application

🤖 AI-Powered Resume Matching
Upload resume (PDF)
Resume vs Job Description comparison
Match score generation
Resume improvement suggestions using LLMs

📈 Analytics & Insights
Job relevance scoring
Role-wise and company-wise application analysis
Application success trends

🧠 Agentic AI Workflow User Goal │ ▼ Job Discovery / Input │ ▼ Relevance Scoring Agent │ ▼ Resume Matching Agent │ ▼ Decision Agent (Apply / Improve / Skip) │ ▼ Execution Layer (Lovable Full-Stack App) │ ▼ Feedback Loop (Application Status Updates)
Lovable acts as the execution layer, converting agent decisions into a real, deployed product with UI, backend APIs, and database.
